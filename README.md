# Supermarket-Sales-Performance-Dashboard

## Project Overview

This project aims to analyze supermarket sales performance using Microsoft Excel. An interactive dashboard was developed to monitor key business metrics, identify sales trends, understand customer behavior, and evaluate product performance.

The dashboard helps users explore sales data from different perspectives and gain insights that can support data-driven business decisions.


## Project Objectives
- Monitor overall sales performance using key performance indicators (KPIs).
- Analyze monthly sales trends and average order value.
- Compare sales performance across different regions.
- Understand customer profiles, membership status, and customer segments.
- Identify top-performing product categories by sales revenue and profit.
- Provide interactive filters for exploring different aspects of business performance.

## Business Questions

This dashboard is designed to answer questions such as:

- How does sales revenue change over time?
- Which regions contribute the most revenue?
- Which customer segments generate the most sales?
- How does average order value change over time?
- Which product categories contribute the most revenue and profit?
- How does customer membership status relate to sales performance?
